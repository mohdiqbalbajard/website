The Ledger Backup

Privacy

The Ledger Backup is an internal tool of Iqbal Global Group. It runs on the Group's own server and, each day, saves a copy of the Group's own records to the Group's own storage account.

It is not offered to the public. It has one user, the Group itself. It can reach only the files that it has itself placed in that account, and nothing else held there.

It collects no information from visitors to this website or from any member of the public, and it shares nothing with anyone.
